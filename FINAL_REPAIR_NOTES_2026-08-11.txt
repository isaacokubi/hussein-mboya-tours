COHERENT TOURS — FINAL REPAIR NOTES
Date: 11 August 2026

Repairs applied to the uploaded Hussein Mboya Tours MERN project:

1. Admin Roles & Permissions
   - Serialized default RBAC bootstrap so simultaneous Roles/Permissions requests cannot race into duplicate-key 500 errors.
   - Kept default role/permission self-healing.
   - Improved API validation/duplicate error responses.

2. Vehicles
   - Fixed capacity handling so NaN/invalid capacity is rejected as a clear 400 validation message instead of a 500 Mongoose error.
   - Added frontend numeric validation before submission.
   - Added year validation.
   - Preserved multipart vehicle image upload.

3. Guide / Driver Assignments
   - Assignment notifications are now created even when Staff.user was missing.
   - Staff accounts are automatically linked to matching User accounts by email when possible.
   - In-app notifications include tour details and the correct dashboard action URL.
   - SMS/WhatsApp attempts remain non-blocking.
   - Added a professional Driver Dashboard and /driver/dashboard route.
   - Guide Dashboard now displays persistent assignment notifications.

4. Customer Tour Images
   - Customer/public tour cards now understand the project's real media structure:
     featuredImage + gallery, while remaining compatible with legacy images/image fields.
   - Tour details, Featured Tours and Wishlist now use the same media normalization and API-relative URL handling.
   - Added a reliable local hero image fallback.

5. Customer Reviews
   - Review submission is available from completed Booking Details.
   - Completed/finished bookings and completedAt are recognized.
   - Backend review ownership supports website user bookings and compatible customer snapshot email matching.
   - Approved reviews exclude deleted records.
   - Existing admin review approval/rejection/rating recalculation remains connected.

6. Agent Portal
   - Removed the mismatched dashboard permission gate; the authenticated agent middleware remains the security boundary.
   - Fixed frontend response mapping so the dashboard reads the backend statistics correctly.
   - Added upcoming bookings, total guests and wallet balance data.
   - Added working quick-action links and recent booking activity.

7. General Professionalization
   - Added persistent notification loading to NotificationContext.
   - Added driver role routing/redirect support.
   - Added driver dashboard UI consistent with the guide operations dashboard.
   - Improved validation error responses globally.

Verification completed:
- All server JavaScript files pass `node --check`.
- Client relative imports resolve to existing local files.
