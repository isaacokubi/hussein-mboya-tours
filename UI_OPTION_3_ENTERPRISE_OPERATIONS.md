# UI Option 3 — Enterprise Operations

The client UI has been restyled around an enterprise tour-operations control center.

## Design direction
- Operations-first navigation
- Bookings, finance, fleet, staff and schedules are first-class modules
- Dense but readable tables/cards
- Desktop sidebar with mobile drawer
- Consistent green operations palette
- Role-specific workspaces for Admin, Tour Manager, Agent, Guide and Driver
- Customer dashboard retains the same business data while adopting the operations visual language

No payment business rules were intentionally changed by this UI pass.
