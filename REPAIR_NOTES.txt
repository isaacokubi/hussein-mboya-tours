First admin bootstrap:
  cd server
  npm install
  npm run create:admin -- "Admin Name" admin@example.com 0712345678 StrongPassword123!

Then configure server/.env with at least:
  MONGODB_URI
  JWT_SECRET
  CLIENT_ORIGINS

For live notifications configure:
  AT_API_KEY
  AT_USERNAME
  AT_SENDER_ID (optional)
  WHATSAPP_API_URL
  WHATSAPP_ACCESS_TOKEN

For payments/media/email also configure the existing M-Pesa, Cloudinary and SMTP environment variables used by the project.
