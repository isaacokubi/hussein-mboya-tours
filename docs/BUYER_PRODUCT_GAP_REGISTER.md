## Acceptance rule

A buyer should not rely solely on repository documentation. The buyer should run the system, inspect the code, reproduce the build/deployment, test integrations, and verify the ownership/licensing position before completing an acquisition.

## Commercial completion roadmap

### Phase 1 — Buyer technical assessment

- Clone repository
- Install dependencies
- Run automated checks
- Review architecture
- Review security
- Review integrations
- Review IP/dependencies

### Phase 2 — Buyer product completion

- Resolve identified defects
- Complete missing UX
- Complete provider integrations
- Complete KRA/eTIMS certification path
- Configure production infrastructure
- Rebrand

### Phase 3 — Launch acceptance

- Production deployment
- Payment acceptance
- Invoice/eTIMS acceptance
- Tenant-isolation acceptance
- Backup/restore acceptance
- Monitoring
- Operational documentation

### Phase 4 — Commercialization

- Buyer-owned branding
- Buyer pricing
- Sales/marketing
- Customer onboarding
- Support process
- Product roadmap
