# Public tour categories API

`GET /api/categories` (inventory entry 199) uses `categoryRoutes.js` router-wide `resolveTenant`, with no JWT or role guard. The controller calls `requireTenantId()` and queries active `TourCategory` records for current tenant, newest first. Success 200 `{success:true,categories:[...]}`. No query/path/body fields; read-only. Missing tenant or database errors go to centralized error handling. This public catalog endpoint does not initialize defaults; admin category listing has separate lazy default seeding behavior documented in [admin experience contracts](admin-experiences.md). Source: `server/routes/categoryRoutes.js`, `server/controllers/categoryController.js`, `TourCategory` model and tenant filter. No dedicated caller/test found in this search; source-only review.
