# GLOBAL TOURS
## Existing Tour & Travel Management SaaS Platform — Acquisition Opportunity

### Executive summary

An existing Kenya-focused multi-tenant tour and travel management platform is available for acquisition by a software company, travel-technology company, ERP/POS provider, eTIMS integrator, or strategic technology buyer.

The opportunity is to acquire the existing software asset and source code, complete the remaining engineering and compliance work, rebrand it, and commercialize it as a buyer-owned product.

### What the buyer gets

- Existing React/Vite web application
- Node/Express backend
- Firebase/Firestore architecture
- Multi-tenant platform foundation
- Tours and destinations
- Customers
- Bookings
- Payments
- M-Pesa integration architecture
- Stripe/card architecture
- Invoicing
- Finance/accounting
- Supplier/procurement workflows
- Profitability workflows
- Corporate accounts
- Accommodation and airport-transfer foundations
- Website/API integration
- Security and operational safeguards
- Production configuration and runbooks
- KRA eTIMS/OSCU integration foundation

### Why acquire instead of starting from zero?

The buyer receives an established software foundation with substantial business logic, data models, integrations, security controls and documentation already developed.

The buyer can therefore focus its engineering budget on completion, certification, product refinement, branding and commercialization rather than recreating the entire platform.

### eTIMS status

The product includes an OSCU integration foundation and supporting documentation.

**KRA certification is not claimed.**

A buyer should complete the KRA sandbox, taxpayer/device configuration, item/tax mapping, certification/vetting and production acceptance process before making compliance claims.

### Ideal buyer

- Kenyan software company
- ERP/POS company
- eTIMS integrator
- Travel-tech company
- Hospitality technology company
- SaaS company seeking a travel vertical
- ICT company with an existing customer base
- Strategic buyer seeking an existing multi-tenant business platform

### Transaction

The preferred transaction is an **exclusive source-code and intellectual-property acquisition**, subject to due diligence and a definitive agreement.

Possible deal structures include:

1. Full asset/IP purchase
2. Asset purchase plus transition support
3. Exclusive licence with purchase option
4. Upfront payment plus agreed earn-out/royalty
5. Strategic acquisition subject to technical acceptance

The final structure is negotiable.

### Due diligence package

Prospective buyers can be given access to:

- Technical demonstration
- Repository review
- Architecture documentation
- Test evidence
- Deployment documentation
- eTIMS implementation documentation
- Known-issues/gap register
- IP and dependency schedule
- Handover plan

Sensitive credentials and customer data should not be shared during initial diligence.

### Seller positioning

This should be presented as a **software asset acquisition opportunity**, not as a website sale and not as a request for freelance development.

### Indicative commercial positioning

No fixed valuation is asserted in this document.

The seller should establish an asking price after confirming:

- IP ownership
- software completeness
- remaining development effort
- working integrations
- deployment reproducibility
- documentation quality
- customer/revenue evidence, if any
- exclusivity
- included domains/brands/accounts
- buyer's intended commercial use
